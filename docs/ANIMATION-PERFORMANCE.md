# 鼠标演示与动画性能记录

日期：2026-09-26。仅本机绘制与模拟输入证据，没有连接 Thor。

## 交互范围

带壳模式左键按住 ABXY、系统键和下方肩键条；按住十字键并拖动切换方向/斜向；拖动摇杆偏转，松开归中；右键按住摇杆演示 L3/R3。捕获丢失、失焦、禁用、隐藏或切换模式释放鼠标状态。视频封面播放与单图平移保留。

用户选择仅演示外壳动画。`ShellPointer` 只在 `PreviewBox` 中与真实输入合并，真实输入对象不变；不会向设备发命令，不进入 `.input.csv` 或视频导出时间线。

## 卡顿原因与调整

此前动态控件使用整体缓存：十字键变化也会重算两个摇杆网格及灯光，动画时还会分配整块大位图；窗口变大后逐像素光照开销进一步放大。

- `ControlLayers` 使用 10 个可复用 PArgb 图层，只有对应姿态、配色或尺寸改变才重画。十字键和 ABXY 不触发静止摇杆/灯光计算。
- 预览接收画面只请求屏幕区域刷新；动画只请求变化的控件区域。静止停止动画定时器。
- `PreviewBox` 使用独立 15ms 定时调度和单调时钟，按实际 elapsed 平滑倾斜/偏转与按压力度，去掉窗口输入轮询中的第二次平滑。15ms 是请求间隔，不是实测帧率。
- 摇杆姿态正余弦只计算一次；固定网格角度与灯源采样预计算。灯碗覆盖判断提前排除无贡献像素，不降低网格、滚花或反射质量。

仍共享原来的 `DeviceArt`、`Stick3D`、`Dpad3D`、`LampLight` 渲染代码；灯环和灯碗固定，杆帽保持有体积的网格。按钮压力插值使侧壁高度、倒角和接触阴影连续变化。

## 测量方法

`tools/measure-animation.ps1` 用系统 Framework 编译器、优化开关编译 `tools/AnimationCheck.cs` 与全部源码，无需 ADB。使用彩虹配色（开灯），固定正弦/余弦模拟姿态，预热 8 次后测 90 次，记录平均、中位数和 P95。预览场景调用正式 OnPaint，包含完整绘制；新实现每步推进 1/60 秒，但这不是定时器/屏幕刷新测量。

修改前记录 `evidence/animation-before.txt`，交付源码记录 `evidence/animation-after-final.txt`。以下为同电脑两次采样，单位 ms；系统负载会影响结果，不视为跨机器保证。

|---|---|---|
| 直接绘制全部控件，双摇杆动态 | 26.19 / 26.11 / 27.21 | 20.11 / 19.98 / 21.61 |
| 灯碗单独绘制 | 3.60 / 3.53 / 3.89 | 2.87 / 2.69 / 4.11 |
