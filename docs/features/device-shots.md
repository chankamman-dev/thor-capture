# 掌机截图（图库「电脑 / 掌机」切换）

工作台左侧图库标题旁有「电脑 / 掌机」切换。选「掌机」时，图库显示 Thor 上 `/sdcard/Pictures/Screenshots` 里的截图，预览、带壳、双屏、导出图片都照常可用。

## 工作方式

- `src/Features/DeviceShots/DeviceShots.cs`：`AdbShotDevice` 通过 `adb exec-out` 列目录（一次 `stat -c %s:%Y:%F:%n *`）、逐张 `cat` 读取、`rm` 删除，并对删除的文件发媒体扫描广播，让系统相册同步去掉。只处理 `[A-Za-z0-9._-]` 组成的文件名，命令里不需要任何引号；其他名字直接跳过。不需要 root。
- `DeviceShotMirror` 把掌机截图镜像到 exe 旁的 `device-shots/<序列号>/`，并改成 ThorCapture 自己的命名，这样图库、配对、带壳预览都不用改：
  - 1920×2160 的 `Thor_*_dual.png`（上屏在上，1240 宽的下屏居中在下）拆成 `thor-upper-…` / `thor-lower-…` 一对；
  - 1920×1080 记为上屏，1240×1080 记为下屏，原样保存不重新编码；其他尺寸记为 `thor-shot-…`，JPG/WebP 转成 PNG；
  - 时间取自文件名（`Screenshot_yyyyMMdd-HHmmss`、`Thor_yyyyMMdd_HHmmss`），否则用掌机文件时间；本地文件的修改时间设为该时间（图库按它分日期）。
  - `.thor-device-index.txt` 记录每个本地文件来自哪个掌机文件（名字、大小、时间）。再次同步只读新增或改变的文件，掌机上已删除的从镜像里去掉。最新的先读，三张并行；中途断开时已读的保留。
- `MainForm.DeviceShots.cs`：切到「掌机」时先显示上次的镜像，再后台同步（状态栏显示进度，约每秒刷新一次图库）。标题行的刷新按钮重新同步；复制按钮和右键「复制到电脑图库」把选中的截图（连同配对的另一屏）复制到保存目录，已存在的不覆盖。删除键在掌机模式下会确认后**永久删除掌机上的原图**，拼在一张图里的上下屏一起删除；删完再列一次目录，只把确实删掉的从镜像去掉。新截图、录屏或更换保存目录会自动切回「电脑」。
- 设置 `shots.serial` 记住上次的掌机，掌机没连接时仍可浏览上次的镜像。

## 验证

- `tests/DeviceShotsTests.cs`（18 项）：列目录解析、时间、拆分像素、索引、增量同步、删除后同步、断开后保留、主窗口切换与配对预览。
- 2026-11-07 实机只读检查（未删除任何文件）：159 张截图，列目录 86 ms，首次同步 15 秒得到 178 个本地文件（19 张双屏图拆分），无变化时再同步 150 ms。样张 `evidence/ui-check/window-device-shots.png`。
- 掌机上的删除只在假设备上测试过，实机删除尚未执行。
